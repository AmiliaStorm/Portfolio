Overview

Biological age clocks are usually validated against chronological age, a convenient but imperfect proxy for the thing that actually matters: health risk. Levine et al.'s Phenotypic Age (2018) was built differently — it was derived directly from a mortality-risk model, using nine routine blood biomarkers.

This project asks whether a machine learning model, trained only on raw biomarkers with no prior clinical knowledge, can match that formula on its own terms: predicting who died during follow-up, not just who "looked older."

Research question

Can a machine learning model match a peer-reviewed clinical aging formula at predicting real mortality outcomes?

Formula validation

Does Levine's Phenotypic Age actually separate those who died during follow-up from those who survived, in this dataset?

Model comparison

How does a Random Forest trained directly on mortality outcomes compare to the formula's discrimination ability (AUC / C-statistic)?

Feature importance

Which biomarkers does an unconstrained model learn to weight most heavily, and do they match the formula's own coefficients?

Model robustness

How do different ensemble methods (Random Forest vs. Gradient Boosting) behave on a small, imbalanced mortality outcome?

Key findings

Formula validation

+7.5 years higher biological age among those who died

Participants who died during follow-up had an average Phenotypic Age 7.5 years above their chronological age, while surviving participants averaged 1.7 years below — confirming the formula captures a real mortality signal in this dataset.

Model comparison

Random Forest (0.842) nearly matched PhenoAge (0.859)

A Random Forest trained with no prior knowledge of clinical risk structure came within 0.02 AUC of a peer-reviewed, expert-calibrated formula. Gradient Boosting trailed at 0.801, overfitting on the small number of deaths.

Analysis scale

2,531 adults, 109 recorded deaths

Five NHANES 2015-2016 component files were linked to the NCHS mortality file through December 2019, yielding a complete-case sample with a 4.3% observed death rate.

Key findings

What the models agreed on — and where they diverged

AUC (C-statistic)

Levine PhenoAge: 0.859 · Random Forest: 0.842 · Gradient Boosting: 0.801. All three substantially outperform chance (0.5).

Age, creatinine and RDW dominate

The Random Forest's own feature importances (age 40%, creatinine 15%, RDW 12%) closely track independent findings in the aging biomarker literature — learned with no formula given to it.

Random Forest beat Gradient Boosting

With only 109 deaths, Gradient Boosting's sequential error-correction overfit to noise in the minority class. Random Forest's bagging was more robust on this small, imbalanced outcome.

Matching, not beating

The honest conclusion: an unconstrained model matched a decades-validated clinical formula. That's a meaningful result in itself, without overclaiming superiority.

-- Join biomarker tables + mortality outcome on SEQN

CREATE VIEW phenoage_mortality_input AS
SELECT
    d.SEQN,
    d.RIDAGEYR AS age,
    b.LBXSAL AS albumin,
    b.LBXSCR AS creatinine,
    g.LBXGLU AS glucose,
    h.LBXHSCRP AS crp,
    c.LBXRDW AS rdw,
    m.mortstat,
    m.permth_exm
FROM DEMO d
LEFT JOIN BIOPRO b ON d.SEQN = b.SEQN
LEFT JOIN GLU g ON d.SEQN = g.SEQN
LEFT JOIN HSCRP h ON d.SEQN = h.SEQN
LEFT JOIN CBC c ON d.SEQN = c.SEQN
INNER JOIN MORTALITY m ON d.SEQN = m.SEQN;
# Levine et al. 2018 Phenotypic Age

xb = (
    -19.9067
    + (-0.0336 * albumin_gL)
    + (0.0095 * creatinine_umolL)
    + (0.1953 * glucose_mmolL)
    + (0.0954 * math.log(crp_mgdL))
    + (0.3306 * rdw)
    + (0.0804 * age)
)

M = 1 - math.exp(
    (-1.51714 * math.exp(xb)) / 0.0076927
)

pheno_age = 141.50225 + (
    math.log(-0.00553 * math.log(1 - M))
    / 0.090165
)
# Cross-validated Random Forest on mortality

skf = StratifiedKFold(
    n_splits=5, shuffle=True, random_state=42
)

model = RandomForestClassifier(
    n_estimators=300,
    max_depth=5,
    min_samples_leaf=10,
    class_weight="balanced",
    random_state=42
)

proba = cross_val_predict(
    model, X, y, cv=skf, method="predict_proba"
)[:, 1]
# Compare formula vs. ML on identical outcome

auc_phenoage = roc_auc_score(
    y, phenoage_score
)

auc_rf = roc_auc_score(
    y, proba_rf
)

auc_gbm = roc_auc_score(
    y, proba_gbm
)

Limitations

Interpreting the results cautiously

Modest event count

Only 109 deaths were available to train and evaluate the ML models, limiting statistical power and increasing variance in AUC estimates.

No claim of superiority

The ML model matched, but did not clearly outperform, Phenotypic Age — a meaningful result given the formula's clinical validation history, not a shortfall.

Older data cycle

NHANES mortality linkage files are not yet available for the most recent (2017–March 2020) cycle, so this analysis uses 2015–2016 data instead.

Complete-case sample

Participants missing any of the nine biomarkers were excluded, which may not be representative of the full surveyed population.

Future work

Extending the analysis

01

Extend to the 2017–March 2020 cycle once its mortality linkage file is released by NCHS.

Tuned XGBoost

Test regularization-tuned XGBoost to see whether it can overcome the overfitting seen with untuned Gradient Boosting on this small sample.

External validation

Test whether the trained Random Forest generalizes to a held-out NHANES cycle rather than only cross-validated folds within one cycle.
