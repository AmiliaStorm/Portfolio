Project overview

Can biological age biomarkers predict real mortality outcomes?

Many biological age models are evaluated by how closely they reproduce chronological age. This project instead focuses on a more meaningful biological outcome: mortality.

NHANES demographic, laboratory and mortality data were combined into a structured database and used to calculate Levine's Phenotypic Age.

The same mortality outcome was then used to evaluate Random Forest and Gradient Boosting models, allowing their predictive performance to be compared directly with the published Phenotypic Age model.

Building the analysis dataset

NHANES data originate from multiple demographic and laboratory datasets. Participant identifiers are used to connect these sources with mortality follow-up information.

SQLite provides a structured environment for organizing the data before the biological age and machine learning analyses are performed in Python.

Key findings

What the analysis showed.

01

Phenotypic Age performed best

The published model achieved the strongest mortality discrimination with an AUC of 0.859.

02

Random Forest came very close

The Random Forest reached an AUC of 0.842, approaching the performance of the established biological age model.

03

Gradient Boosting performed lower

Gradient Boosting achieved an AUC of 0.801 on the same mortality outcome.

04

Mortality was the real target

Model performance was assessed against recorded mortality rather than simply measuring agreement with chronological age.
