Project overview

Predicting biological risk instead of chronological age.

Biological age clocks are often compared with chronological age. But chronological age is only a proxy for the outcome that matters clinically: differences in health and mortality risk.

Levine's Phenotypic Age takes a different approach. It uses routine blood biomarkers together with chronological age to estimate mortality-related biological aging.

This project asks whether machine learning models trained directly on the same mortality outcome can learn a similarly useful risk signal without being given the published formula.

-- Join biomarker tables + mortality outcome on SEQN

CREATE VIEW phenoage_mortality_input AS
SELECT
    d.SEQN,
    d.RIDAGEYR AS age,
    b.LBXSAL AS albumin,
    b.LBXSCR AS creatinine,
    g.LBXGLU AS glucose,
    h.LBXHSCRP AS crp,
    c.LBXRDW AS rdw,
    m.mortstat,
    m.permth_exm
FROM DEMO d
LEFT JOIN BIOPRO b
    ON d.SEQN = b.SEQN
LEFT JOIN GLU g
    ON d.SEQN = g.SEQN
LEFT JOIN HSCRP h
    ON d.SEQN = h.SEQN
LEFT JOIN CBC c
    ON d.SEQN = c.SEQN
INNER JOIN MORTALITY m
    ON d.SEQN = m.SEQN;
# Levine et al. Phenotypic Age

xb = (
    -19.9067
    + (-0.0336 * albumin_gL)
    + (0.0095 * creatinine_umolL)
    + (0.1953 * glucose_mmolL)
    + (0.0954 * math.log(crp_mgdL))
    + (0.3306 * rdw)
    + (0.0804 * age)
)

M = 1 - math.exp(
    (-1.51714 * math.exp(xb))
    / 0.0076927
)

pheno_age = 141.50225 + (
    math.log(
        -0.00553 * math.log(1 - M)
    )
    / 0.090165
)
# Cross-validated Random Forest

skf = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=42
)

model = RandomForestClassifier(
    n_estimators=300,
    max_depth=5,
    min_samples_leaf=10,
    class_weight="balanced",
    random_state=42
)

proba = cross_val_predict(
    model,
    X,
    y,
    cv=skf,
    method="predict_proba"
)[:, 1]
# Compare formula vs ML models

auc_phenoage = roc_auc_score(
    y,
    phenoage_score
)

auc_rf = roc_auc_score(
    y,
    proba_rf
)

auc_gbm = roc_auc_score(
    y,
    proba_gbm
)

print("PhenoAge:", auc_phenoage)
print("Random Forest:", auc_rf)
print("Gradient Boosting:", auc_gbm)

Limitations

Interpreting the results cautiously.

109 mortality events

The modest event count limits statistical power and increases uncertainty around model performance.

No claim of superiority

Random Forest approached, but did not outperform, Phenotypic Age.

Single NHANES cycle

Evaluation was performed within the 2015–2016 cycle rather than through independent external validation.

Complete-case sample

Participants missing required biomarkers were excluded from the final modeling dataset.
