Bioinformatics / Single-Cell Transcriptomics

COVID-19 Single-Cell Transcriptomics

Single-cell RNA-seq analysis of 81,000+ peripheral blood immune cells from COVID-19 patients and healthy controls. Using R and Seurat, immune-cell populations were identified and condition-associated transcriptional changes were investigated, with focused analysis of monocyte states.

Bioinformatics / Mortality Prediction

Biological Age Predictor & Mortality Model

A SQL and machine learning pipeline benchmarking Levine's Phenotypic Age formula against a self-built Random Forest model, evaluated on real NHANES mortality outcomes rather than a chronological-age proxy.

SQL Python scikit-learn NHANES
