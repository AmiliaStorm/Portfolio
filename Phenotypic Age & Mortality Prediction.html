Project overview

Comparing a published biological-age model with machine learning on real mortality outcomes.

Rather than training against chronological age, this project evaluates biological-age signals against observed mortality. Levine's Phenotypic Age serves as the clinical benchmark.

The analysis then compares that benchmark with Random Forest and Gradient Boosting models trained from NHANES biomarker data.

Key findings

What the comparison showed.

01

Phenotypic Age remained strongest

The published model achieved the best mortality discrimination with an AUC of 0.859.

02

Random Forest came close

Random Forest reached 0.842 AUC, only 0.017 below the published model.

03

Gradient Boosting was lower

Gradient Boosting reached 0.801 AUC on the same mortality-focused comparison.

04

Real outcome, not an age proxy

The comparison was evaluated against recorded mortality rather than simply predicting chronological age.

Limitations

Interpreting the result carefully.

01

Modest event count

Only 109 recorded deaths were available for the mortality-focused comparison.

02

No claim of superiority

Random Forest nearly matched, but did not outperform, Phenotypic Age.

03

Single NHANES cycle

The analysis is based on the NHANES 2015–2016 cohort used in this project.

04

Complete-case analysis

Participants without the required analysis inputs were excluded.
