Beslutningstre fra bunnen av

Implementerte en beslutningstreklassifikator i Python for å undersøke hvordan ulike urenhetsmål påvirker modellen.

Python Klassifikasjon Modellevaluering
Biologiske data / Pågående studieprosjekt

Modellering av biologisk alder og dødelighet

Utforsker biomarkørbasert biologisk alder og modellering av dødelighet med NHANES-data og tilknyttede dødelighetsdata.

  • Arbeider med kliniske data og biomarkørdata i tabellformat.
  • Undersøker PhenoAge sammen med maskinlæringsmetoder.
  • Utvikler arbeidsflyter for databehandling og modellevaluering.
Python pandas scikit-learn SQL

  • Utforsker prosessene fra DNA til translasjon og sekresjon.
  • Integrerer 3D-modeller og nettleserbasert rendering.
JavaScript Three.js WebGL Blender
